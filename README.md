# Relatório — Fila de Mensagens

**Documento em PDF sobre filas de mensagens, organizado para leitura e consulta.**

Este repositório publica o relatório como artefato documental. Não contém uma aplicação de mensageria, um broker configurado ou um ambiente de testes executável.

## Documento principal

### [Ler o relatório em PDF](relatorio_fila_mensagens.pdf)

Abra o arquivo no visualizador do GitHub ou em um leitor de PDF. O conteúdo técnico e as conclusões devem ser consultados no documento; este README fornece a apresentação e o caminho de acesso, não uma reprodução do relatório.

## Estrutura

## Leitura local

```bash
git clone https://github.com/dlr-1337/relatorio-fila-mensagens.git
cd relatorio-fila-mensagens
```

Abra `relatorio_fila_mensagens.pdf`. A leitura não exige instalação de dependências nem execução de comandos de build.

## Escopo

O repositório disponibiliza um documento, não garante a reprodução de experimentos nem entrega uma implementação de fila. Código, arquivos de configuração ou instruções de laboratório precisariam ser publicados separadamente para constituir uma demonstração executável.
